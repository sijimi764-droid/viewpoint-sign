# Requirements

The authoritative product baseline is maintained under `governance/`.

This directory is for detailed requirements derived from the baseline without silently changing it.

## Rules

- Do not override a closed Human Gate here.
- If a detailed requirement conflicts with the baseline, the baseline wins until a new Human Gate or approved baseline revision changes it.
- Every implementation-relevant requirement should be testable or explicitly marked as requiring later physical calibration.
- PoC-A detailed requirements are currently captured in `../poc/POC_A_SPEC.md` and `../tests/POC_A_ACCEPTANCE.md`.
