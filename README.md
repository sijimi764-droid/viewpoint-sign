# viewpoint-sign

Warehouse-oriented spatial signage system that distributes a sign across multiple physical planes so that it remains readable from a practical viewing zone.

## Current status

- Requirements baseline: v1.0
- Human Gates HG-01 through HG-08: closed
- Current phase: PoC-A detailed design
- Current development gates: G0 → G1 → G2 → G3

## Core principle

Optimize for warehouse usability rather than perfect one-point anamorphosis:

**readability → readable-zone breadth → installation-error tolerance → use of existing surfaces → installation simplicity → requested size/position → near-field appearance**
